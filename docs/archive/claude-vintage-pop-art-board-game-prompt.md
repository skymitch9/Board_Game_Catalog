Design a colorful board-game website using a muted vintage pop-art comic theme.

## Visual direction

- Use a warm, aged-paper background in soft cream or beige.
- Use a restrained palette of mustard yellow, dusty blue, muted brick red, faded coral, and dark charcoal.
- Avoid neon colors, pure white backgrounds, and highly saturated primary colors.
- Add subtle halftone-dot patterns inspired by vintage comic printing.
- Use thick charcoal outlines, slightly offset shadows, and gently imperfect panel alignment.
- Style content sections like comic-book panels without making the layout feel cluttered.
- Use speech bubbles, caption boxes, starbursts, and small “POW!” or “NEW!” graphics sparingly.
- Keep textures subtle so text remains easy to read.
- Use slightly rotated decorative elements to create a handmade printed-comic feeling.

## Typography

- Use **Bangers** or **Luckiest Guy** for major headlines.
- Use a clean, rounded sans-serif font for navigation, descriptions, and longer text.
- Use comic display fonts only for short headings and decorative labels.
- Headlines can use cream lettering with a dark outline and a restrained brick-red offset shadow.

## Layout

- Create a bold comic-style hero section featuring a board-game illustration, a short headline, supporting text, and one clear call-to-action.
- Present featured games as organized comic panels with cover art, player count, playing time, difficulty, and genre.
- Include sections for featured games, game categories, upcoming events, community favorites, and newsletter signup.
- Keep the navigation and important actions clean and conventional.
- Use generous spacing so the design feels playful but not chaotic.
- Make the website fully responsive and accessible, with strong contrast, visible focus states, and comfortable text sizes.

## Suggested palette

- Aged cream: `#F4EAD5`
- Warm paper: `#E7D6AF`
- Mustard: `#C8A75C`
- Dusty blue: `#7699A0`
- Deep dusty blue: `#526F78`
- Brick red: `#9D5146`
- Faded coral: `#C89082`
- Charcoal ink: `#282522`

## Overall mood

The result should feel like a charming 1950s–1970s printed comic or illustrated board-game instruction booklet. It should be energetic, nostalgic, welcoming, and tactile—but not childish, fluorescent, visually overwhelming, or difficult to navigate.

Build the page with polished, production-quality details. Use realistic board-game content instead of placeholder text. Maintain consistent spacing, typography, colors, panel borders, and shadow treatments throughout.
